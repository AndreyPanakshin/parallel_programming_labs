# Лабораторная работа №5: Запуск MPI-умножения матриц на суперкомпьютере «Сергей Королёв»

## Описание файлов

| Файл | Назначение |
|------|------------|
| `mpi_matmul.cpp` | Исходный код программы на C++ с использованием MPI. Реализует распределённое умножение матриц с применением `MPI_Scatterv` и `MPI_Gatherv`. |
| `gen_data.py` | Скрипт на Python для генерации тестовых матриц заданного размера со случайными значениями. |
| `run_1.pbs` | Batch-скрипт PBS для запуска программы на 1 процессе. |
| `run_2.pbs` | Batch-скрипт PBS для запуска программы на 2 процессах. |
| `run_4.pbs` | Batch-скрипт PBS для запуска программы на 4 процессах. |
| `submit_jobs.pbs` | Скрипт системы управления заданиями PBS для автоматической отправки всех задач в очередь суперкомпьютера. |
| `benchmark.csv` | Файл с результатами экспериментов (размер матрицы, количество процессов, время выполнения в мс). |
| `draw_plots.py` | Скрипт для построения графиков зависимости времени выполнения и ускорения от размера матрицы. |

## Запуск программы 

### Требования

```bash
# Загрузка необходимых модулей 
module purge
module load intel/mpi4

# Проверка доступных модулей
module list

# Компиляция MPI-программы
mpicxx -std=c++11 -O3 mpi_matmul.cpp -o mpi_matmul

# Конвертация окончаний строк для совместимости с Linux
sed -i 's/\r$//' submit_jobs.pbs gen_data.py

# Запуск всех тестов
sbatch submit_jobs.pbs

# Просмотр статуса заданий
squeue -u $USER

# Просмотр результатов после выполнения
cat benchmark.csv
```
# Процесс верификации
1. Скрипт gen_data.py генерирует две случайные матрицы размером N×N
2. MPI-программа запускается на заданном количестве процессов
3. Выполняется распределённое умножение матриц на кластере
4. Результат сохраняется в result.dat
5. Время выполнения фиксируется и записывается в benchmark.csv
