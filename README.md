# Лабораторная работа №3: Параллельное перемножение матриц (MPI)

## Описание файлов

| Файл | Назначение |
|------|------------|
| `matrix_mpi.cpp` | Исходный код программы на C++ с использованием MPI. Реализует распределённое умножение матриц с применением `MPI_Bcast`, `MPI_Scatterv`, `MPI_Gatherv`. |
| `check_result.py` | Скрипт на Python для автоматической верификации результатов. Сравнивает вывод MPI-программы с эталонным вычислением через NumPy. |
| `benchmark.sh` | Bash-скрипт для автоматизированного запуска тестов с различными размерами матриц (200, 400, 800, 1200, 1600, 2000) и количеством процессов (1, 2, 4, 8). |
| `draw_graphs.py` | Скрипт для построения графиков зависимости времени выполнения и ускорения от числа процессов. |
| `Makefile` | Файл сборки проекта. Компилирует программу с необходимыми флагами MPI. |
| `matrix.txt` | Входной файл, содержащий две матрицы. Генерируется автоматически при запуске тестов. |
| `result.txt` | Выходной файл с результатом умножения. Включает матрицу-результат, время выполнения, количество процессов и объём вычислений. |
| `stats.csv` | Файл со статистикой. Содержит данные для всех тестовых конфигураций (размер матрицы, количество процессов, время, операции, объём данных). |

# Запуск программы

## Требования
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y openmpi-bin libopenmpi-dev python3 python3-pip
pip3 install numpy matplotlib
```

## Сборка
- `make all`

## Запуск тестов
- `make run-all`

## Построение графиков
- `make graphs`

## Полное тестирование
- `make experiment`

# Процесс проверки
1. MPI-программа умножает матрицы и сохраняет результат в output/result.txt
2. check_result.py считывает входные матрицы из data/matrices.txt
3. NumPy вычисляет эталонное произведение A × B
4. Выполняется сравнение результата MPI с эталоном
5. Выводится максимальная погрешность и статус проверки (УСПЕШНО /ОШИБКА)
